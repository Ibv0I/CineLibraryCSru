# Этап 33 — источник КиноПоиск API Unofficial

- В ручном окне выбора фильма добавлен переключатель источника TMDb / КиноПоиск.
- Добавлен `KinopoiskClient` для поиска, получения подробностей, списка изображений и данных об актёрах/съёмочной группе.
- Все запросы КиноПоиска и загрузка его изображений используют общий `ProxySettings.CreateHttpClient`, поэтому действуют текущие настройки HTTP/SOCKS5 прокси.
- Для `movie.nfo` записываются идентификатор и рейтинг выбранного источника (`kinopoisk` или `tmdb`).
- В настройках добавлено поле API-ключа КиноПоиск. Токен сохраняется в настройках приложения в зашифрованном DPAPI виде для текущей учётной записи Windows.
- Ключ не вшит в исходники или ZIP: его нужно один раз вставить в Настройки → КиноПоиск API Unofficial → «Сохранить ключ КиноПоиска». Это не позволяет случайно опубликовать персональный токен в публичном репозитории.
- Автоматическая подготовка по первому результату пока остаётся на TMDb; новый источник доступен в ручном выборе фильма.
- Статическая проверка: 23 XAML-файла корректно разбираются как XML; полная сборка не выполнялась, потому что в рабочей среде нет .NET SDK/MSBuild.
