## Область дальнейшего перевода после уточнения пользователя

Продолжать перевод нужно только для интерфейса, который остаётся доступным пользователю в текущей конфигурации приложения. Разделы **TV Shows / эпизоды** и **TMDb-диалоги** скрыты и исключаются из дальнейшего аудита остатка. Английские строки внутри этих скрытых экранов не считаются задачей перевода, пока эти экраны не будут возвращены.

Приоритет оставлен за видимыми элементами основного окна, библиотеки фильмов, карточки и подробностей фильма, дисков, списков, статистики, коллекций, резервного копирования, дубликатов, обзора и настроек. Системные сообщения сторонних библиотек и внутренние идентификаторы не переводятся, если они не отображаются пользователю напрямую.

Количество оставшихся строк следует считать только по этой области, а не по всему исходному коду без учёта скрытых экранов. Статический поиск по XAML помогает выявить строки, но не заменяет проверку динамического текста во время работы приложения.
