# Movie Library — этап 5: пакетная подготовка медиатеки

## Что добавлено
- Кнопка «Сохранить выбранные фильмы» запускает пакетную подготовку всех строк, для которых вручную выбрано совпадение TMDb.
- Совпадения TMDb и выбранные изображения остаются привязаны к строкам во время пакетного запуска; неподготовленные строки не сохраняются случайно.
- Перед запуском показывается общее подтверждение, включая количество файлов `movie.nfo`, `poster.jpg` и `fanart.jpg`, которые могут быть заменены.
- Для каждого фильма создаются NFO и изображения тем же путём, что и при индивидуальном сохранении. NFO записывается последним, чтобы сканер не увидел незавершённую подготовку.
- После пакетной операции сканируется выбранная папка в рамках соответствующего диска, чтобы обновить базу CineLibrary сразу после подготовки.
- В статусе отображается текущий фильм и итоговое количество успешных/неудачных операций.

## Проверки
- XAML XML-синтаксис и структура ZIP проверяются перед выдачей архива.
- Компиляция .NET в этой среде недоступна (`dotnet` SDK отсутствует); сборку следует проверить GitHub Actions.
