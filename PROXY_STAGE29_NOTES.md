# Movie Library — этап 29: настройки прокси

## Добавлено
- В окно настроек добавлен раздел «Прокси для внешних подключений».
- Типы: SOCKS5 и HTTP.
- Поля адреса, порта и необязательной авторизации.
- Отдельные кнопки сохранения настроек и проверки соединения.
- По умолчанию прокси выключен; без него используется прямое соединение.
- Настройки сохраняются в приложении. Пароль защищается Windows DPAPI для текущей учётной записи Windows.
- TMDb API и CDN изображений используют общий фабричный метод сетевого клиента.
- Проверка обновлений (если будет включена в будущем) тоже использует этот фабричный метод.
- SOCKS5 реализован через SocketsHttpHandler.ConnectCallback, включая логин/пароль и удалённое разрешение DNS через имя узла.
- Локальные операции с файлами, сканирование медиатеки и SQLite не затрагиваются.

## Использование
1. Откройте «Настройки».
2. В разделе прокси включите переключатель.
3. Выберите SOCKS5 или HTTP и укажите адрес и порт.
4. При необходимости включите авторизацию и заполните логин/пароль.
5. Нажмите «Проверить соединение».
6. Нажмите «Сохранить прокси». Изменения применяются к новым сетевым операциям.

Если прокси выключен, приложение использует прямое соединение.
