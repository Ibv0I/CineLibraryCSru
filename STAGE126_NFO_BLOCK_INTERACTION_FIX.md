# Stage 126 — исправление взаимодействия с блоками редактора NFO

## Что исправлено
- Перетаскивание запускается только с отдельной полосы-заголовка блока. Поля ввода и кнопки не перехватываются механизмом перемещения.
- Изменение размера запускается отдельным маркером в нижнем правом углу.
- Размер меняется по двум осям: ширина и высота.
- Для перетаскивания используется стабильная система координат окна; перестановка применяется при отпускании мыши, чтобы перемещение элемента в StackPanel не сбрасывало захват указателя.
- Порядок, ширина и высота сохраняются в отдельном JSON-файле `NfoEditorBlocks.settings.json` и восстанавливаются при открытии.
- Ошибка загрузки пользовательских настроек не блокирует открытие редактора.

## Сохранность данных
Изменения затрагивают только визуальную компоновку редактора. Запись NFO, модели дорожек, рейтинги и обработчики полей не менялись.

## Проверки
- XAML разобран как XML.
- ZIP проверен на целостность.
- Полная сборка C# не запускалась: .NET SDK недоступен в среде подготовки.
