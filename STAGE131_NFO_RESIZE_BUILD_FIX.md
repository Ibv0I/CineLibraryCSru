# Stage 131 — исправление ошибок сборки изменения размера NFO

Исправлены две ошибки компиляции Stage 130:

- Убран недоступный в WinUI 3 тип `Windows.UI.Input.Pointer` из сигнатуры `FinishBlockResize`. Захват указателя освобождается непосредственно в обработчике `PointerReleased`; при `PointerCaptureLost` освобождение уже не требуется.
- Удалён `BlockResizeHandle : Border`, поскольку `Border` запечатан. Зоны изменения размера теперь обычные экземпляры `Border`; направление края хранится в `ConditionalWeakTable`, а системный курсор задаётся через `ProtectedCursor`.

Обработчики движения, отпускания и потери захвата указателя сохранены. Полная сборка .NET в среде подготовки не выполнялась.
