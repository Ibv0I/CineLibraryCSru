Этап 18 — исправления окна подготовки и редактора метаданных

- Убрана кнопка удаления у корневых папок; крестик добавлен в каждую карточку папки с фильмом.
- В окне исключений удалена строка про сохранение JSON, расширено содержимое и добавлены отступы для кнопки удаления, чтобы крестик не обрезался.
- При добавлении папки, находящейся внутри исключения, показывается сообщение с просьбой убрать её из исключений.
- Выбор изображения хранит выбранный элемент отдельно от состояния GridView, чтобы кнопка «Выбрать» использовала именно отмеченный файл.
- В редакторе метаданных переставлены кнопки: «Подтвердить выбор» слева, «Отмена» справа.
- При редактировании фильма на странице деталей используются текущие изображения из кэша приложения (с резервным поиском poster.jpg/fanart.jpg в папке фильма), а не первый вариант TMDb.
- Подтверждение редактора сохраняет основные поля метаданных и связи жанров, режиссёров, сценаристов и актёров в базе данных даже если изображения не менялись.

Проверки: XML-разбор 23 XAML-файлов пройден; скобки в изменённых C# файлах сбалансированы. Полная сборка .NET не выполнялась в этой среде.
- Для кнопки редактирования оформления отключены фокусная рамка и участие в Tab-навигации, чтобы убрать лишние визуальные переключения при открытии окна.
