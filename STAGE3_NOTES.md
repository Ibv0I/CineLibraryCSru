Этап 3 — подробности фильма и выбор изображений

Добавлено:
- загрузка подробностей фильма из TMDb после ручного сопоставления;
- отображение описания, даты выхода, рейтинга/числа голосов, длительности, жанров, стран, режиссёра и актёров;
- загрузка вариантов постеров и фонов через TMDb Images API;
- отдельные предварительные просмотры и выбор постера/фона;
- сохранение выбранных метаданных и путей изображений в объекте папки только на время текущего сеанса.

Файлы медиатеки на этом этапе не создаются и не изменяются. Запись movie.nfo, poster.jpg и fanart.jpg остаётся этапом 4.

Архив подготовлен из предыдущего архива v10. Сборка dotnet в этой среде не выполнялась; требуется проверить GitHub Actions.
