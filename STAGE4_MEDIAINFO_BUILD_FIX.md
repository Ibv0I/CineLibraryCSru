# Исправления сборки MediaInfo

- Убран `using` для `MediaInfoWrapper`: тип не реализует `IDisposable`.
- Исправлено чтение полей видео, аудио и субтитров под MediaInfo.Wrapper.Core 26.1.0. Перечисления преобразуются в строки, свойства, которых нет в типизированном API, читаются через безопасную рефлексию.
- Для субтитров используется коллекция `Subtitles`.
- Длительность в NFO: стандартный `runtime` в минутах плюс человекочитаемый элемент `duration` в формате `H ч MM мин`.
- Устранены nullable warnings при активации главного окна; удалено неиспользуемое поле `_loading`.

Проверена целостность ZIP и отсутствие дублирующихся путей. Сборка .NET в среде подготовки не выполнялась.
