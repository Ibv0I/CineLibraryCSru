# Stage 5 — исправление SQLite foreign key при обновлении медиатеки

Причина: страница подготовки могла запускать Scanner для диска, который ещё не был зарегистрирован в таблице `drives`. При добавлении найденных фильмов таблица `movies` ссылается на `drives(volume_serial)`, поэтому SQLite возвращал `FOREIGN KEY constraint failed`.

Исправление в `Views/MoviePreparationPage.xaml.cs`:
- перед сканированием регистрируется диск через `DatabaseService.AddDrive` (операция идемпотентна);
- выбранная папка регистрируется как корень сканирования через `AddDriveRoot`, если её ещё нет;
- статус «Медиатека обновлена» показывается только после фактического завершения сканирования.

Сборка .NET в этой среде не выполнялась.
