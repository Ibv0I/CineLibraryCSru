# Этап 6 — несколько папок и автоматическая подготовка

- Выбор папки добавляет её к уже выбранным корневым папкам, а не заменяет предыдущую.
- Повторный выбор той же папки не создаёт дубликат.
- Поиск кандидатов охватывает все добавленные корни и не дублирует уже найденные каталоги.
- «Автоподготовка всех фильмов» ищет фильм в TMDb, при наличии года сначала использует его, затем при отсутствии результатов повторяет поиск без года. Выбирается первый результат, загружаются полные данные, изображения, постер, фон и фото актёров (если включён флажок), создаётся movie.nfo.
- Если совпадение не найдено или у первого результата нет постера/фона, папка остаётся в списке с описанием проблемы для ручной обработки.
- После завершения запускается обновление медиатеки по всем добавленным корневым папкам.
- Существующие файлы заранее учитываются в подтверждении; отмена не запускает процесс.
