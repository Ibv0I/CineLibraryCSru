# Отчёт локализации — шаг 25 (пакетная проверка видимого интерфейса)

Область: только доступные разделы приложения. Скрытые TV Shows/эпизоды и TMDb-диалоги исключены.

## Исправления
- Добавлена локализация кнопки «Show all» в блоке актёров.
- Исправлен ключ подсказки восстановления фильма из «Просмотрено и удалено»: вызов передавал строку без начальных переводов строки, а словарь содержал ключ с `\n\n`, из-за чего перевод не находился.
- Начальный заголовок библиотеки теперь берётся через LocalizationService, а не отображается напрямую на английском.
- Сверены аргументы TranslateText в видимом C#-коде с картой локализации; из найденных обычных текстовых строк обработаны две реальные отсутствующие записи. Имена ресурсов (например, MicaDescription) намеренно не трактуются как пользовательский текст.

## Проверки
- RESW/XML и XAML/csproj проверяются отдельно скриптом; наборы ключей языковых ресурсов должны совпадать.
- Полная сборка C# и запуск на Windows не выполнялись.
